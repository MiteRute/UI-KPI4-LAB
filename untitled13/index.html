UI for students

На цій сторінці представлено 10 елементів інтерфейсу користувача

1. Radiobutton

Призначення: Використовується для вибору лише одного варіанта з обмеженого переліку взаємовиключних опцій

Оберіть спосіб доставки:

2. Checkbox

Призначення: Дозволяє обрати декілька варіантів одночасно

Додаткові послуги та згода:

3. Text input

Призначення: Поле для введення користувачем довільного рядка тексту

4. Tabs

Призначення: Організація та розділення контенту за секціями в одному вікні без перезавантаження сторінки.

Вкладка: Опис

Детальна інформація про товар його призначення та технічні характеристики.

Вкладка: Відгуки покупців

Коментарі та оцінки користувачів які вже придбали цей товар.

Вкладка: Гарантія та повернення

Умови повернення протягом 14 днів та контакти сервісних центрів.

5. Button

Призначення: Ініціація певної дії користувача відправка форми, скасування, скидання даних або запуск функції

6. Text label

Призначення: Текстовий підпис до елемента керування.

7. Link

Призначення: Навігація між сторінками, перехід до зовнішніх веб-ресурсів або стрибок до певного елемента на поточній сторінці.

Посилання на Вікіпедію | Перейти до поля текстового вводу

8. Tooltip

Призначення: Коротка контекстна довідка, яка з'являється при наведенні курсору миші на елемент.

Наведіть курсор миші на підкреслений термін: UI

9. Dropdown list

Призначення: Компактний вибір одного значень із довгого списку варіантів що не займає зайвого місця на екрані до розкриття.

10. Data grid

Призначення: Впорядковане двовимірне відображення структурованих даних у вигляді рядків та стовпців для зручного читання аналізу та порівняння інформації.
